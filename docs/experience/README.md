设计或调整实验时先检索对应经验，并阅读其来源、模型、并行方式和评测口径。重做已有失败方案时说明变更条件或新依据。经验中的局部结论不能扩大成所有模型、所有配置的通用保证。

收尾顺序为“总结结果 → 检查经验增量 → 更新导航”。有新认识时更新已有主题，新主题才增加文件；记录与经验互相引用。没有新增经验时直接说明，不生成空模板。具体维护方法见 [文档管理规范](../MANAGEMENT.md)。
